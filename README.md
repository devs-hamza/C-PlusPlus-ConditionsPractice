# C++ Conditions Practice

A collection of beginner-friendly C++ programs for practicing **conditional statements** and **switch statements**.

## 📚 Practice Sections

### 1. If / Else If / Else — 45 Programs
Programs **01–45** focus on decision-making using:
- `if`
- `else if`
- `else`
- Relational and logical conditions
- Basic input validation and comparisons

### 2. Switch Statements — 15 Programs
Programs **46–60** focus on:
- `switch`
- `case`
- `break`
- `default`

### 3. Nested Switch Statements — 15 Programs
Programs **61–75** focus on using a `switch` statement inside another `switch`.

This repository is being built as a **C++ practice collection** to improve understanding of control structures through small, independent programs.
